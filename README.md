# بررسی اجمالی

این برنامه میاد روی سرور خارجتون نه لزوما سرور اصلی نصب میشه بعد میاد  آیپی سرور های ایرانتون رو با دامه هایی که با این آیپی ها ست شده  برسی میکنه بعد هر 120 ثانیه وضعیت اتصال tcp سرورها رو چک میکنه ،   هر کدوم از سرورها به مشکل بخوره و  پینگی دریافت نشه ، به صورت رندوم آیپی اون ساب دامنه رو تغییر میده و   هر 20 ثانیه اون سروری که  مشکل اتصال داره  چک میکنه  زمانی که اتصال سرور دوباره برقرار شد  ساب دامین رو به حالت اول برمیگردونه . .

# توجه
- همه سرورهای ایرانتون باید  تانل شده  باشن

- برای مثال اگه شما یک سرور خارج دارید حتما باید روی تمام سرور های ایران تانل شده باشه و با هر ایپی ایران بشه متصل شد

- از نسخه‌ی جدید به بعد نصاب می‌تونه برنامه رو به عنوان یک سرویس systemd نصب کنه؛ در این حالت حتی بعد از ریست شدن سرور هم برنامه خودکار اجرا میشه و نیازی به اجرای دستی مجدد نیست (در ادامه توضیح داده شده).


# راهنمای نصب
برای نصب کافیه دستور زیر رو اجرا کنید

```bash
curl -Ls https://raw.githubusercontent.com/Free-Guy-IR/cloudflareAuto_change_ip/main/install.sh | bash
```

نصاب به‌صورت خودکار پایتون، pip، venv و git رو (در صورت نیاز) نصب می‌کنه، پروژه رو دریافت می‌کنه، یک محیط مجازی پایتون (venv) می‌سازه و کتابخانه‌های لازم رو داخل همون venv نصب می‌کنه؛ بعدش ویزارد پیکربندی (رنگی و تعاملی، با کتابخانه‌ی rich) اجرا میشه و در نهایت می‌پرسه که آیا برنامه به‌صورت سرویس systemd نصب بشه یا نه.

## ویزارد پیکربندی

وقتی ویزارد اجرا شد، مرحله به مرحله این اطلاعات رو ازتون می‌پرسه (در هر مرحله مقدار پیش‌فرض داخل پرانتز نمایش داده میشه و با زدن Enter همون مقدار انتخاب میشه، ورودی IP/پورت/عدد هم اعتبارسنجی میشه):

**۱) دامنه‌ها (Zones)**
```
چند دامنه (Zone) دارید؟
Zone ID دامنه 1:
Zone ID دامنه 2:
```

**۲) سرورهای بکاپ (ایران)**
```
چند سرور دارید؟
آی‌پی سرور 1:
پورت TCP تانل‌شده‌ی سرور 1:
اولویت سرور 1 (1 = بیشترین اولویت):
```
پورت TCP باید حتما پورت تانل‌شده باشه، تا اگه تانل قطع شد برنامه بتونه اون رو تشخیص بده.

**۳) Cloudflare**
```
ایمیل اکانت Cloudflare:
Global API Key:
```
Global API Key رو از پروفایل اکانت کلودفلرتون بردارید. این مقدار روی ترمینال به صورت مخفی (مثل رمز عبور) وارد میشه و نمایش داده نمیشه.

**۴) تلگرام**
```
توکن ربات تلگرام:
Chat ID تلگرام:
```
توکن ربات هم مثل Global API Key به صورت مخفی وارد میشه.

**۵) بازه‌ی بررسی**
```
فاصله‌ی بررسی سرورها (ثانیه):
```
مقدار پیش‌فرض 120 ثانیه‌ست.

در پایان یک جدول خلاصه از تمام مقادیر (با مخفی‌کردن بخشی از توکن‌ها) نشون داده میشه و ازتون تایید نهایی گرفته میشه قبل از ذخیره در فایل `.env`.

## اجرای دائمی (بعد از پیکربندی)

اگه در حین نصب گزینه‌ی سرویس systemd رو تایید کرده باشید، برنامه از همون لحظه به صورت پس‌زمینه و دائمی در حال اجراست و با ریست شدن سرور هم دوباره خودکار بالا میاد. وضعیتش رو می‌تونید با این دستور ببینید:
```bash
systemctl status cloudflare-auto-ip
```

اگه سرویس رو نصب نکردید (یا systemd روی سرورتون در دسترس نیست)، باید برنامه رو داخل `screen` اجرا کنید تا با قطع شدن اتصال SSH متوقف نشه:
```bash
screen -S cloudflare-ip
cloudflareAuto_change_ip/venv/bin/python3 cloudflareAuto_change_ip.py
```
(خروج از screen بدون متوقف کردن برنامه: `Ctrl+A` سپس `D`)

## تغییر تنظیمات بعدی

اگه بعدا خواستید مقادیر (IP سرورها، توکن‌ها، بازه‌ی بررسی و ...) رو تغییر بدید، کافیه ویزارد رو دوباره با فلگ `--reconfigure` اجرا کنید (نسخه‌ی قبلی `.env` به صورت `.env.bak` بکاپ گرفته میشه):
```bash
cd cloudflareAuto_change_ip
venv/bin/python3 cloudflareAuto_change_ip.py --reconfigure --setup
```
اگه سرویس systemd نصب کرده بودید، بعد از تغییر تنظیمات یک بار سرویس رو ری‌استارت کنید:
```bash
sudo systemctl restart cloudflare-auto-ip
```
