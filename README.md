# CloudflareAuto ChangeIP

ابزاری برای مانیتورینگ خودکار سلامت تونل میان یک سرور خارج و چند سرور داخل ایران، با سوییچ خودکار رکورد DNS در Cloudflare هنگام بروز قطعی و اطلاع‌رسانی آنی از طریق تلگرام.

## معرفی

این برنامه روی یک سرور خارج (نه لزوماً سرور اصلی سرویس) نصب می‌شود و آی‌پی سرورهای ایران را که پشت رکوردهای DNS مشخصی در Cloudflare قرار دارند، به‌طور دوره‌ای بررسی می‌کند. در صورتی که یکی از سرورها دچار قطعی شود (پینگ یا اتصال TCP برقرار نشود)، رکورد DNS مربوطه به‌صورت خودکار به یکی دیگر از سرورهای بکاپ (بر اساس اولویت تعریف‌شده) تغییر می‌کند و پس از برقراری مجدد اتصال با سرور اصلی، رکورد به حالت اولیه بازمی‌گردد.

**پیش‌نیاز زیرساختی:** تمام سرورهای ایران باید از طریق تونل به سرور خارج متصل باشند. برای مثال، اگر یک سرور خارج دارید، باید با تمام سرورهای ایران تانل برقرار کرده باشد تا این ابزار بتواند وضعیت هرکدام را از طریق همان تونل بررسی کند.

## ویژگی‌ها

- بررسی دوره‌ای وضعیت اتصال (Ping و TCP) سرورها با فاصله‌ی زمانی قابل تنظیم
- سوییچ خودکار رکورد DNS به سرور بکاپ بعدی بر اساس اولویت، در صورت قطعی مکرر
- بازگشت خودکار به IP اصلی پس از تایید پایداری مجدد اتصال
- پشتیبانی از چند دامنه (Zone) و چند سرور بکاپ به‌طور هم‌زمان
- اطلاع‌رسانی فوری تغییرات و وضعیت سرورها از طریق ربات تلگرام
- ویزارد پیکربندی رنگی و تعاملی با اعتبارسنجی ورودی‌ها و ورود امن اطلاعات حساس
- امکان اجرا به‌عنوان سرویس `systemd` برای پایداری در برابر ریست شدن سرور

## پیش‌نیازها

- یک سرور لینوکسی (دبیان/اوبونتو) با دسترسی root یا sudo، که به تمام سرورهای ایران تانل شده باشد
- اکانت Cloudflare با دسترسی به Global API Key
- یک ربات تلگرام برای دریافت اعلان‌ها

## نصب

نصب و پیکربندی اولیه با اجرای دستور زیر روی سرور خارج انجام می‌شود:

```bash
curl -Ls https://raw.githubusercontent.com/Free-Guy-IR/cloudflareAuto_change_ip/main/install.sh | bash
```

این اسکریپت به‌صورت خودکار مراحل زیر را انجام می‌دهد:

1. نصب پیش‌نیازهای سیستمی (Python 3، pip، venv، git، curl)
2. دریافت آخرین نسخه‌ی پروژه از مخزن گیت‌هاب
3. ساخت یک محیط مجازی پایتون (`venv`) مجزا و نصب کتابخانه‌های مورد نیاز درون آن
4. اجرای ویزارد پیکربندی تعاملی برای دریافت اطلاعات لازم
5. پیشنهاد نصب برنامه به‌عنوان سرویس `systemd` جهت اجرای دائمی

## پیکربندی (ویزارد تعاملی)

ویزارد پیکربندی اطلاعات لازم را طی چند مرحله دریافت می‌کند. در هر مرحله مقدار پیش‌فرض (در صورت وجود) داخل پرانتز نمایش داده می‌شود و با فشردن Enter انتخاب می‌شود؛ ورودی‌های IP، پورت و اعداد نیز اعتبارسنجی می‌شوند.

**۱) دامنه‌ها (Zones)**
```
چند دامنه (Zone) دارید؟
Zone ID دامنه 1:
Zone ID دامنه 2:
```

**۲) سرورهای بکاپ (ایران)**
```
چند سرور دارید؟
آی‌پی سرور 1:
پورت TCP تانل‌شده‌ی سرور 1:
اولویت سرور 1 (1 = بیشترین اولویت):
```
پورت واردشده باید متعلق به همان پورت تانل‌شده باشد، تا در صورت قطع شدن تونل نیز برنامه قادر به تشخیص آن باشد.

**۳) Cloudflare**
```
ایمیل اکانت Cloudflare:
Global API Key:
```
Global API Key از بخش پروفایل اکانت Cloudflare قابل دریافت است. این مقدار روی ترمینال به‌صورت مخفی (مشابه ورود رمز عبور) دریافت می‌شود و نمایش داده نمی‌شود.

**۴) تلگرام**
```
توکن ربات تلگرام:
Chat ID تلگرام:
```
توکن ربات نیز مانند Global API Key به‌صورت مخفی دریافت می‌شود.

**۵) بازه‌ی بررسی**
```
فاصله‌ی بررسی سرورها (ثانیه):
```
مقدار پیش‌فرض ۱۲۰ ثانیه است.

در پایان، جدولی خلاصه از تمام مقادیر واردشده (با پنهان‌سازی بخشی از توکن‌های حساس) نمایش داده می‌شود و پیش از ذخیره‌ی نهایی در فایل `.env`، تاییدیه گرفته می‌شود.

## اجرای دائمی

در صورتی که در حین نصب، گزینه‌ی سرویس `systemd` را تایید کرده باشید، برنامه از همان لحظه به‌صورت پس‌زمینه و دائمی اجرا می‌شود و پس از ریست شدن سرور نیز به‌طور خودکار مجدداً راه‌اندازی می‌شود. وضعیت سرویس با دستور زیر قابل مشاهده است:

```bash
systemctl status cloudflare-auto-ip
```

در صورتی که سرویس نصب نشده باشد (یا `systemd` روی سرور در دسترس نباشد)، برنامه باید درون `screen` اجرا شود تا با قطع شدن اتصال SSH متوقف نگردد:

```bash
screen -S cloudflare-ip
cloudflareAuto_change_ip/venv/bin/python3 cloudflareAuto_change_ip.py
```

خروج از `screen` بدون متوقف کردن برنامه: ابتدا `Ctrl+A` و سپس `D`.

## تغییر تنظیمات

برای تغییر مقادیر پیکربندی‌شده (آی‌پی سرورها، توکن‌ها، بازه‌ی بررسی و غیره) در آینده، کافی است ویزارد را با فلگ `--reconfigure` مجدداً اجرا کنید. نسخه‌ی پیشین فایل `.env` پیش از بازنویسی، به‌صورت `.env.bak` پشتیبان‌گیری می‌شود:

```bash
cd cloudflareAuto_change_ip
venv/bin/python3 cloudflareAuto_change_ip.py --reconfigure --setup
```

در صورت استفاده از سرویس `systemd`، پس از هر تغییر تنظیمات لازم است سرویس یک بار مجدداً راه‌اندازی شود:

```bash
sudo systemctl restart cloudflare-auto-ip
```
